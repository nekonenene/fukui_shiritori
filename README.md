# 福井しりとりスクリーンセーバー

「福井」から始まる、名字の漢字しりとりを流すだけのページです。

こちら： **https://nekonenene.github.io/fukui_shiritori/**


## 使い方

`dist/index.html` をブラウザで開くだけです。

- `Space`: 一時停止 / 再開
- `R`: 最初から
- `F`: 全画面

## ルール

- 「福井」から開始
- 全国名字ランキング2000位以内の名字だけで接続
- 前の名字の最後の漢字 → 次の名字の最初の漢字でつなぐ
- 2秒ごとに進行、行き止まりで「おわり」→ 5秒後に再開

## 出典

名字データ：[名字由来net 全国名字ランキング](https://myoji-yurai.net/prefectureRanking.htm)（2026年4月時点）
